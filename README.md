# Frontend for [my IOT project backend](https://github.com/CKMPeter/IOT_Smart_Farming_BE) about smart farming.
## Frameworks and technologies
- NODE & npm
- REACT.JS
- Firebase
- Rechart
## Features
- Providing a UI for the ESP 32 which display the humidity, the temperature and the state of the soil.
- Communicating with firebase for data storage.
- Representing the data in a graph for easier debug.
## Setup for development
- clone this repo
- run `npm install`
- then run `npm run build` for a ESP ready version.
- if want to debug of you do not have a ESP at hand then use `node server.js` for simulation perposes.
